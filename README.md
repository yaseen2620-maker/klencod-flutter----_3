# بريق - نسخة Flutter المطورة

- الحفاظ على تركيبات المنتجات الـ16 والنسب الموجودة في ملف HTML الأصلي كما هي.
- حاسبة كميات الخامات حسب كمية الإنتاج بالكيلو.
- إدارة التركيبات: إضافة منتج، تعديل تركيبة، وإضافة/حذف خامات.
- تسجيل سعر شراء الكيلو لكل خامة.
- تقدير تكلفة الخامات وسعر التكلفة لكل كيلو، ومقارنة إجمالي البيع بالتكلفة قبل المصروفات.
- حفظ التعديلات والأسعار محليًا على الجهاز باستخدام SharedPreferences.

## التشغيل
1. افتح المجلد الرئيسي الذي يحتوي على `pubspec.yaml` مباشرة كمشروع Flutter.
2. نفّذ `flutter pub get`.
3. شغّل التطبيق على جهاز أو محاكي Android.
4. لبناء APK: `flutter build apk --release`.

## ملاحظات
- أسعار الخامات تبدأ فارغة؛ يجب إدخال أسعار الشراء الفعلية.
- الخامات التي لا تحتوي على نسبة رقمية (مثل ضبط pH حسب القياس) لا تدخل في حساب التكلفة.
- لم تتم إضافة تصدير Excel/PDF أو سجل دفعات التصنيع بعد.
- التركيبات محفوظة كما وردت في ملف HTML الأصلي، ولا يعني ذلك اعتمادها فنيًا أو ضمان سلامتها. يلزم اختبار الجودة وpH والثبات والتوافق والسلامة قبل الإنتاج التجاري.

## وحدة المخزون والحسابات (الإصدار 3)
- تسجيل مشتريات ومبيعات ومصروفات وديون عملاء وديون موردين.
- تحديث رصيد المخزون تلقائيًا من كميات الشراء والبيع المسجلة.
- ملخص إجمالي المبيعات والمشتريات والمصروفات وربح تقديري.
- حذف حركة قديمة مع إعادة احتساب الرصيد والإجماليات.
- جميع السجلات تحفظ محليًا على الجهاز.

تنبيه محاسبي: الربح المعروض تقديري على أساس متوسط تكلفة الشراء المسجلة للصنف؛ أدخل أرصدة أول المدة والمصروفات الفعلية يدويًا قبل الاعتماد عليه في قرارات مالية. الديون مسجلة كسجل منفصل ولا تُخصم تلقائيًا من المبيعات أو المشتريات، ولا يوجد تحصيل/سداد جزئي أو فواتير ضريبية في هذه النسخة.

## الفواتير وكشوف الحساب والتقارير (الإصدار 4)
- حقل رقم فاتورة اختياري في حركات البيع والشراء.
- تسجيل تحصيلات العملاء وسداد الموردين كحركات مستقلة.
- كشف مجمع لكل اسم عميل/مورد: إجمالي التعاملات والتحصيل/السداد والرصيد.
- ملخص مبيعات اليوم والشهر ومشتريات الشهر ومصروفات الشهر.
- الرصيد المستحق للعملاء = المبيعات + مديونيات العملاء المسجلة - التحصيلات.
- الرصيد المستحق للموردين = المشتريات + مديونيات الموردين المسجلة - السداد.
- لم يتم بعد ربط التحصيل أو السداد بفاتورة بعينها أو دعم دفعات متعددة على فاتورة محددة؛ رقم الفاتورة مرجع نصي فقط.
